# 晶燦鑽石與明亮珍珠

晶燦鑽石與明亮珍珠是 ILCA 製作的 Unity 作品，其 IL2CPP 遊戲程式碼直接在 Pia 上通訊。這些頁面描述的是 1.3.0 版本，場景包括聯盟室（寶可夢中心 2 樓，左側接待員，直接選「是」）和地下大洞窟。

## 狀態

在零售硬體上已實現：

| 功能 | 細節 |
|---|---|
| 主機會話中的一個席位 | 只需要 `prod.keys` 和 LDN 口令；每個資料包都能解密；傳送路徑與主機的密文逐位元組一致 |
| 傳輸 | Local、Mesh Station 與 Mesh Protocol 握手，RTT 計時器，雙向的可靠傳輸 |
| 聯盟室中的一個角色 | 可以行走、顯示交換表情、觸發遊戲的問候對話 |
| 交換 | 組裝好的寶可夢被接受並儲存；多次交換可在一次關聯中連續進行（[交換](bdsp_trade.md#the-completed-trade)） |
| 開設房間 | 進入聯盟室的主機會加入開設好的房間並進行交換（[開設房間](bdsp_session.md#hosting)） |
| 球殼 | 合成好的球殼會帶著玩家持有的貼紙進入收藏（[協議頁面](bdsp_protocol.md)） |
| 記錄混合、對戰大廳 | 可達到主機的記錄以及它選定的六隻寶可夢 |
| 地下大洞窟 | 角色可以在地面上行走；主機的秘密基地可被讀取出來 |
