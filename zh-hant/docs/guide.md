# 從這裡開始

pokeldn 通過本地無線與 Switch 或 Switch 2 上的寶可夢遊戲進行交換。插在 USB 上的 ESP32 板子就是無線模組。主機上不需要安裝任何東西。

## 所需材料

- 一塊經典 ESP32 板子（ESP32-D0WD、WROOM-32E），帶 USB 序列埠橋；或通過原生 USB 口連線的 ESP32-S3、ESP32-C3、ESP32-C6。它們都使用 2.4 GHz。不支援 S2 板子。Seeed Studio XIAO ESP32C3 需裝上附帶的天線；XIAO ESP32C6 使用內建天線。
- 一根 USB 資料線。只能充電的線不會顯示序列埠。
- 從你自己的 Switch 中匯出的 `prod.keys`。應用只會索要一次。
- 「遊戲」頁面中的七款遊戲之一。

## 首次執行

1. 「裝置」頁：插上板子，點選「無線」旁邊的「安裝」。應用會識別晶片、寫入韌體，然後自行檢查板子。板子回應後，頁面頂部會顯示「已是最新」。
2. 「遊戲」頁：選擇遊戲和工具。「主持」類工具等待你的主機加入；「加入」類工具則會找到主機自己的搜尋。
3. 要提供的寶可夢：搜尋一個種類並點選「生成」。PKHeX 會為那款遊戲生成一隻合法的寶可夢，訓練家為設定中的訓練家。
4. 開始之前，「會話」面板會列出仍然缺少的內容，並附上修復按鈕。按照「在主機上」下的步驟操作，然後點選「開始」。

帶兩個 USB 口的 ESP32-S3、C3 或 C6 板子只能通過標有 USB 的口與應用通訊。從另一個口（COM 或 UART）刷寫也能成功，但之後板子永遠不會回應；「裝置」頁會說明這一點。插入多塊板子時，用「使用此裝置」選擇會話要用的那一塊。

「更多選項」位於種類下方，可設定性格、特性、性別、攜帶道具、精靈球、親密度、個體值和努力值（Let's Go 中為 AV，傳說 阿爾宙斯中為努力等級）。留空的欄位保持隨機。列表只包含該種類在那款遊戲中能合法擁有的內容，而「生成」會拒絕 PKHeX 判定為非法的組合，並給出原因。交換來的寶可夢只有在設定中的「你的訓練家」就是主機玩家時才保留親密度；火紅和葉綠在每次交換時都會把它設為 70。

「新增交換」位於寶可夢下方，可為一次會話排隊最多六次交換；每完成一次交換就會提供下一隻。它在所有交換工具中都會顯示。每次交換收到的寶可夢都會儲存為單獨的檔案。

可以把檔案拖到應用上：把寶可夢檔案或 Showdown 隊伍（`.txt`）拖到交換區域會填入它，拖到「新增交換」則會按每個檔案排隊一次交換。把禮物檔案拖到「禮物」卡片上會開啟它，把 `.bin` 拖到「裝置」頁的「韌體」卡片上，會在確認後安裝。

主機發送給你的寶可夢會儲存在 `Documents/pokeldn/Received`，並複製一份到銀行。銀行的加號按鈕，或往它的網格里拖放，可匯入寶可夢檔案或整個遊戲存檔：其中每隻合法的寶可夢都會被存入一次，檔案本身保持原樣。來自舊世代遊戲的寶可夢會留下攜帶道具並忘記秘傳學習器，這與 HOME 的傳入方式一致。

## 釋放儲存空間

設定 → 儲存 會顯示可以釋放多少空間。點選「清理本地檔案」，然後點選「清理檔案」，即可刪除儲存的會話記錄、日誌、臨時提供項和未使用的已生成寶可夢。請先儲存錯誤報告所需的記錄。已收到的寶可夢、選中的提供項、金鑰、韌體和設定會保留。清理檔案前請先結束當前執行。

## 火紅與葉綠的語言

神秘禮物的「主機」卡片會顯示版本和自動語言檢測。選擇火紅或葉綠。你在遊戲的好友列表中選擇 pokeldn 之後，遊戲會報告其卡帶程式碼；pokeldn 會在傳送程式碼之前選擇對應語言的禮物指令碼和記憶體地址。兩個版本都支援英語、法語、德語、義大利語、西班牙語和日語。

儲存原生 `.wc3` 時，如果禮物因版本或語言而異，會詢問卡帶資訊。`.pokegift` 會保留所有變體，並在主機連線時選擇正確的那一個。

「高階」中的「訓練家語言」描述的是 pokeldn 自己在連線中的訓練家，它不會選擇主機的語言。

## 基礎與高階

「基本」顯示大多數執行所需的欄位；各遊戲經過測試的設定會在底層應用。「高階」列出該遊戲會話接受的所有選項，並附帶各自的幫助文本。在那裡設定的值會覆蓋「基本」欄位。除非指南或錯誤報告要求改動，否則不要動它。

大多數玩家從不更改的設定位於「高階」頂部，且已預設好：會話自行停止前的時限、無線通道，以及每次執行生成新 PID。「每次執行生成新 PID」會給每隻提供的寶可夢一個新的 PID，使已經接收過它的存檔能再次接收；對於 PID 必須保持不變的檔案（例如活動寶可夢），請關閉它。

## 你自己的寶可夢檔案

「或使用寶可夢檔案」接受從 PKHeX 匯出的檔案。應用會用 PKHeX 檢查它，並在你提供之前顯示它是否合法。非法的寶可夢在被繪製時可能導致另一款遊戲崩潰。

## 神秘禮物

每個神秘禮物工具都以四個選項開始。「使用預設」會發送現成的禮物。在劍與盾中，「官方活動」會列出真實的活動卡片（寶可夢、道具、服裝、對戰點數），並帶有搜尋框。「自行構建」會開啟一個表單：在火紅與葉綠中是帶有文本、交付者和內容的神秘卡片、神秘新聞，或你自己的 ARM 程式碼；在劍與盾中是寶可夢、蛋、道具或對戰點數。「開啟檔案」會發送別人分享的 `.pokegift`、火紅與葉綠上的 `.wc3` 卡片，或劍與盾上的 `.wc8` 卡片。

「自定義」會把預設變成可修改的表單。「傳送前」會顯示主機會收到什麼、何時發生以及適用於哪些卡帶；有問題時會用紅色顯示，且「開始」保持不可用。

在火紅與葉綠中，「遊戲增益」可以讓你更改遊戲的執行方式，例如加速或新增寶可夢跟隨者。選擇增益併發送；它們會立即生效，並在遊戲重啟時停止。若想在重啟後再次使用，請啟用「之後儲存增益」，傳送增益，然後傳送「媽媽恢復你的增益」。每次重啟後，在真新鎮的家中與媽媽對話即可重新開啟。跟隨者總會被儲存。接收另一張神秘卡片會替換媽媽的禮物；再次傳送它，以恢復她開啟已儲存增益的能力。

「讀取存檔」會在會話日誌中顯示結果。訓練家 ID（TID）是訓練家卡片上的數字；裡 ID（SID）通常是隱藏的。隊伍讀數會顯示你上次儲存的隊伍中的每隻寶可夢，以及它的性格、六項個體值（0 到 31 的能力值）和努力值（訓練點數）。這些工具會保持你的存檔和神秘卡片不變。訓練家詳情和隊伍工具還會在「已接收」中儲存一份讀取資料的副本。

「主機程式碼」會在接收禮物時於遊戲內執行。「離線檢查」會先在模擬主機上執行它；會導致選單卡死的程式碼會被拒絕。原生程式碼可以改變正在執行的遊戲或其存檔。請只發送你已檢查過原始碼和行為的程式碼。

「儲存禮物檔案」會儲存選中的禮物，以便重複使用或分享。它無需板子即可工作。

在火紅與葉綠中，「你的存檔」會把整個存檔從 Switch 複製到這臺電腦，或把存檔放回去。「從 Switch 備份」會保持主機的存檔不變；副本會出現在「你的存檔」中，以訓練家命名。「將存檔放到 Switch 上」會把選中的存檔寫到主機自己的存檔旁邊；主機會檢查每個部分，載入並儲存，若出現任何問題則保留舊存檔。請先備份主機。恢復會等到 PKHeX 判定整個隊伍合法後才進行，或者等你開啟「仍然恢復」。

「你的存檔」儲存在 `Documents/pokeldn/Saves`。重新命名以示區分，匯出為 `.sav` 供模擬器或 PKHeX 使用，或用 + 新增一個 `.sav`，也可把它拖到卡片上。「檢視和編輯」會顯示訓練家、隊伍和電腦盒子：更改名字、金錢或代幣，重排或移除隊伍中的寶可夢，新增一隻為該存檔訓練家生成的寶可夢，並檢查某個盒子的合法性。「保留為新存檔」會把結果新增到原存檔旁邊，原存檔保持不變。

## 執行失敗時

- 先點「停止」，然後退出主機的搜尋介面並重新搜尋。大多數遊戲會短暫保留過期的會話。
- 每次執行只改一處。
- 設定 → 「記錄每次會話」→「開啟記錄」會顯示每次會話的錄製；把最近的一次附到錯誤報告中。
