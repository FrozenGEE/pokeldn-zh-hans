# 从这里开始

pokeldn 通过本地无线与 Switch 或 Switch 2 上的宝可梦游戏进行交换。插在 USB 上的 ESP32 板子就是无线模块。主机上不需要安装任何东西。

## 所需材料

- 一块经典 ESP32 板子（ESP32-D0WD、WROOM-32E），带 USB 串口桥；或通过原生 USB 口连接的 ESP32-S3、ESP32-C3、ESP32-C6。它们都使用 2.4 GHz。不支持 S2 板子。Seeed Studio XIAO ESP32C3 需装上附带的天线；XIAO ESP32C6 使用内置天线。
- 一根 USB 数据线。只能充电的线不会显示串口。
- 从你自己的 Switch 中导出的 `prod.keys`。应用只会索要一次。
- 「游戏」页面中的七款游戏之一。

## 首次运行

1. 「设备」页：插上板子，点击「无线」旁边的「安装」。应用会识别芯片、写入固件，然后自行检查板子。板子回应后，页面顶部会显示「已是最新」。
2. 「游戏」页：选择游戏和工具。「主持」类工具等待你的主机加入；「加入」类工具则会找到主机自己的搜索。
3. 要提供的宝可梦：搜索一个种类并点击「生成」。PKHeX 会为那款游戏生成一只合法的宝可梦，训练家为设置中的训练家。
4. 开始之前，「会话」面板会列出仍然缺少的内容，并附上修复按钮。按照「在主机上」下的步骤操作，然后点击「开始」。

带两个 USB 口的 ESP32-S3、C3 或 C6 板子只能通过标有 USB 的口与应用通信。从另一个口（COM 或 UART）刷写也能成功，但之后板子永远不会回应；「设备」页会说明这一点。插入多块板子时，用「使用此设备」选择会话要用的那一块。

「更多选项」位于种类下方，可设置性格、特性、性别、携带道具、精灵球、亲密度、个体值和努力值（Let's Go 中为 AV，传说 阿尔宙斯中为努力等级）。留空的字段保持随机。列表只包含该种类在那款游戏中能合法拥有的内容，而「生成」会拒绝 PKHeX 判定为非法的组合，并给出原因。交换来的宝可梦只有在设置中的「你的训练家」就是主机玩家时才保留亲密度；火红和叶绿在每次交换时都会把它设为 70。

「添加交换」位于宝可梦下方，可为一次会话排队最多六次交换；每完成一次交换就会提供下一只。它在所有交换工具中都会显示。每次交换收到的宝可梦都会保存为单独的文件。

可以把文件拖到应用上：把宝可梦文件或 Showdown 队伍（`.txt`）拖到交换区域会填入它，拖到「添加交换」则会按每个文件排队一次交换。把礼物文件拖到「礼物」卡片上会打开它，把 `.bin` 拖到「设备」页的「固件」卡片上，会在确认后安装。

主机发送给你的宝可梦会保存在 `Documents/pokeldn/Received`，并复制一份到银行。银行的加号按钮，或往它的网格里拖放，可导入宝可梦文件或整个游戏存档：其中每只合法的宝可梦都会被存入一次，文件本身保持原样。来自旧世代游戏的宝可梦会留下携带道具并忘记秘传学习器，这与 HOME 的传入方式一致。

## 释放存储空间

设置 → 存储 会显示可以释放多少空间。点击「清理本地文件」，然后点击「清理文件」，即可删除保存的会话记录、日志、临时提供项和未使用的已生成宝可梦。请先保存错误报告所需的记录。已收到的宝可梦、选中的提供项、密钥、固件和设置会保留。清理文件前请先结束当前运行。

## 火红与叶绿的语言

神秘礼物的「主机」卡片会显示版本和自动语言检测。选择火红或叶绿。你在游戏的好友列表中选择 pokeldn 之后，游戏会报告其卡带代码；pokeldn 会在发送代码之前选择对应语言的礼物脚本和内存地址。两个版本都支持英语、法语、德语、意大利语、西班牙语和日语。

保存原生 `.wc3` 时，如果礼物因版本或语言而异，会询问卡带信息。`.pokegift` 会保留所有变体，并在主机连接时选择正确的那一个。

「高级」中的「训练家语言」描述的是 pokeldn 自己在连接中的训练家，它不会选择主机的语言。

## 基础与高级

「基本」显示大多数运行所需的字段；各游戏经过测试的设置会在底层应用。「高级」列出该游戏会话接受的所有选项，并附带各自的帮助文本。在那里设置的值会覆盖「基本」字段。除非指南或错误报告要求改动，否则不要动它。

大多数玩家从不更改的设置位于「高级」顶部，且已预设好：会话自行停止前的时限、无线信道，以及每次运行生成新 PID。「每次运行生成新 PID」会给每只提供的宝可梦一个新的 PID，使已经接收过它的存档能再次接收；对于 PID 必须保持不变的文件（例如活动宝可梦），请关闭它。

## 你自己的宝可梦文件

「或使用宝可梦文件」接受从 PKHeX 导出的文件。应用会用 PKHeX 检查它，并在你提供之前显示它是否合法。非法的宝可梦在被绘制时可能导致另一款游戏崩溃。

## 神秘礼物

每个神秘礼物工具都以四个选项开始。「使用预设」会发送现成的礼物。在剑与盾中，「官方活动」会列出真实的活动卡片（宝可梦、道具、服装、对战点数），并带有搜索框。「自行构建」会打开一个表单：在火红与叶绿中是带有文本、交付者和内容的神秘卡片、神秘新闻，或你自己的 ARM 代码；在剑与盾中是宝可梦、蛋、道具或对战点数。「打开文件」会发送别人分享的 `.pokegift`、火红与叶绿上的 `.wc3` 卡片，或剑与盾上的 `.wc8` 卡片。

「自定义」会把预设变成可修改的表单。「发送前」会显示主机会收到什么、何时发生以及适用于哪些卡带；有问题时会用红色显示，且「开始」保持不可用。

在火红与叶绿中，「游戏增益」可以让你更改游戏的运行方式，例如加速或添加宝可梦跟随者。选择增益并发送；它们会立即生效，并在游戏重启时停止。若想在重启后再次使用，请启用「之后保存增益」，发送增益，然后发送「妈妈恢复你的增益」。每次重启后，在真新镇的家中与妈妈对话即可重新开启。跟随者总会被保存。接收另一张神秘卡片会替换妈妈的礼物；再次发送它，以恢复她开启已保存增益的能力。

「读取存档」会在会话日志中显示结果。训练家 ID（TID）是训练家卡片上的数字；里 ID（SID）通常是隐藏的。队伍读数会显示你上次保存的队伍中的每只宝可梦，以及它的性格、六项个体值（0 到 31 的能力值）和努力值（训练点数）。这些工具会保持你的存档和神秘卡片不变。训练家详情和队伍工具还会在「已接收」中保存一份读取数据的副本。

「主机代码」会在接收礼物时于游戏内运行。「离线检查」会先在模拟主机上运行它；会导致菜单卡死的代码会被拒绝。原生代码可以改变正在运行的游戏或其存档。请只发送你已检查过源码和行为的代码。

「保存礼物文件」会保存选中的礼物，以便重复使用或分享。它无需板子即可工作。

在火红与叶绿中，「你的存档」会把整个存档从 Switch 复制到这台电脑，或把存档放回去。「从 Switch 备份」会保持主机的存档不变；副本会出现在「你的存档」中，以训练家命名。「将存档放到 Switch 上」会把选中的存档写到主机自己的存档旁边；主机会检查每个部分，加载并保存，若出现任何问题则保留旧存档。请先备份主机。恢复会等到 PKHeX 判定整个队伍合法后才进行，或者等你开启「仍然恢复」。

「你的存档」保存在 `Documents/pokeldn/Saves`。重命名以示区分，导出为 `.sav` 供模拟器或 PKHeX 使用，或用 + 添加一个 `.sav`，也可把它拖到卡片上。「查看和编辑」会显示训练家、队伍和电脑盒子：更改名字、金钱或代币，重排或移除队伍中的宝可梦，添加一只为该存档训练家生成的宝可梦，并检查某个盒子的合法性。「保留为新存档」会把结果添加到原存档旁边，原存档保持不变。

## 运行失败时

- 先点「停止」，然后退出主机的搜索界面并重新搜索。大多数游戏会短暂保留过期的会话。
- 每次运行只改一处。
- 设置 → 「记录每次会话」→「打开记录」会显示每次会话的录制；把最近的一次附到错误报告中。
