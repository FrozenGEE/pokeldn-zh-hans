# 晶灿钻石与明亮珍珠

晶灿钻石与明亮珍珠是 ILCA 制作的 Unity 作品，其 IL2CPP 游戏代码直接在 Pia 上通信。这些页面描述的是 1.3.0 版本，场景包括联盟室（宝可梦中心 2 楼，左侧接待员，直接选「是」）和地下大洞窟。

## 状态

在零售硬件上已实现：

| 功能 | 细节 |
|---|---|
| 主机会话中的一个席位 | 只需要 `prod.keys` 和 LDN 口令；每个数据包都能解密；发送路径与主机的密文逐字节一致 |
| 传输 | Local、Mesh Station 与 Mesh Protocol 握手，RTT 计时器，双向的可靠传输 |
| 联盟室中的一个角色 | 可以行走、显示交换表情、触发游戏的问候对话 |
| 交换 | 组装好的宝可梦被接受并保存；多次交换可在一次关联中连续进行（[交换](bdsp_trade.md#the-completed-trade)） |
| 开设房间 | 进入联盟室的主机会加入开设好的房间并进行交换（[开设房间](bdsp_session.md#hosting)） |
| 球壳 | 合成好的球壳会带着玩家持有的贴纸进入收藏（[协议页面](bdsp_protocol.md)） |
| 记录混合、对战大厅 | 可达到主机的记录以及它选定的六只宝可梦 |
| 地下大洞窟 | 角色可以在地面上行走；主机的秘密基地可被读取出来 |
